1. Executive Summary & Core Philosophy

Autonomous Vision-Language Model (VLM) web agents require full-page screen visual context to reason and perform actions. However, transmitting raw web screens exposes highly sensitive Personally Identifiable Information (PII) — including credentials, Aadhaar/PAN identity cards, banking info, and personal photos — to reasoning servers and foundation model APIs.

The Core Innovation: Our system enforces a strict Zero-Egress On-Device Sandbox. 100% of PII detection and visual redaction is executed locally in the user's browser client before any pixels or DOM descriptors leave the device. The central reasoning engine receives only cryptographically sealed, sanitized frames.

2. High-Level Architectural Layers

Client-Side Tier (Zero-Egress Sandbox)

Chrome Extension Manifest V3 running completely in the user's browser. Extracts DOM AST, executes heuristic & regex PII detectors, paints on an Offscreen Canvas 2D, and applies Set-of-Marks (SoM) action indexing.

Server Reasoning Tier (Local & Offline)

FastAPI microservice executing a local quantized Vision-Language Model (Qwen2-VL-2B-Instruct). Enforces strict air-gapped offline operation with zero internet connectivity and zero telemetry.

4. Key Architectural Decisions (Why X vs Y)

A. Client-Side Masking vs. Server-Side Masking

Decision: 100% Client-Side Masking.
If raw screenshots are transmitted to a server for redaction, the privacy boundary is already breached in transit. By performing all blurring, pixelation, and regex checks on the client in the browser sandbox, raw PII never touches the network adapter.

B. Set-of-Marks (SoM) Tagging vs. Raw Coordinate Prediction

Decision: Pre-indexed Set-of-Marks Visual Action Tags.
Instead of asking the reasoning model to predict fragile x,y pixel coordinates, the client overlays discrete numbered badges (e.g. [0], [1]) on interactable DOM elements. This eliminates coordinate calibration errors and makes agent execution 100% reliable.

C. Offline Local Model vs. Cloud Foundation APIs (OpenAI / Anthropic)

Decision: Air-Gapped Local Inference (HF_HUB_OFFLINE=1).
In sensitive enterprise, defense, and space operations (such as ISRO workflows), outbound network traffic to third-party cloud LLMs is forbidden by policy. Our server operates 100% locally with zero internet egress.
